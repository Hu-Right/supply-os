## 概述

本项目使用以下服务实现验证码发送功能：

| 服务类型 | 服务提供商 | 用途 |
|----------|------------|------|
| 邮件服务 | 阿里云 SMTP (nodemailer) | 注册验证码、找回密码验证码 |
| 短信服务 | 阿里云 SMS | 找回密码短信、手机号绑定/解绑/换绑验证码 |

## 环境变量配置清单

### 完整配置表

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| **邮箱服务** |
| `SMTP_HOST` | ✅ 是 | - | SMTP 服务器地址 |
| `SMTP_PORT` | 否 | `465` | SMTP 端口（465=SSL, 587=TLS） |

| `SMTP_PASS` | ✅ 是 | - | SMTP 登录密码/授权码 |

| `SMS_PROVIDER` | 否 | `mock` | 短信服务商：`aliyun` 或 `mock` |
| `SMS_ACCESS_KEY_ID` | ✅ 是 | - | 阿里云 AccessKey ID |
| `SMS_ACCESS_KEY_SECRET` | ✅ 是 | - | 阿里云 AccessKey Secret |
| `SMS_SIGN_NAME` | 否 | `恒创联众` | 短信签名名称 |
| `SMS_TEMPLATE_CODE` | 否 | `100001` | 默认短信模板 CODE（绑定/解绑场景） |
| `SMS_TEMPLATE_CODE_RESET` | 否 | - | 找回密码专用短信模板 CODE |

## 邮箱服务配置

### 服务商支持

当前支持所有标准 SMTP 服务：

| 服务商 | SMTP 地址 | 端口 | 备注 |
|--------|-----------|------|------|
| 阿里云邮件推送 | `smtpdm.aliyun.com` | 465 (SSL) | 推荐，需开通邮件推送服务 |
| 腾讯企业邮 | `smtp.exmail.qq.com` | 465 (SSL) | - |
| 阿里企业邮 | `smtp.mxhichina.com` | 465 (SSL) | - |
| Gmail | `smtp.gmail.com` | 587 (TLS) | 需开启应用专用密码 |

### 配置步骤（以阿里云为例）

1. 登录 [阿里云邮件推送控制台](https://dm.console.aliyun.com/)
2. 设置发信域名（如 `mail.yourdomain.com`）
3. 配置 DNS 解析（SPF、MX、DKIM 记录）
4. 创建发信地址（如 `noreply@yourdomain.com`）
5. 设置 SMTP 密码
6. 将配置填入环境变量

### 业务场景

| 接口路径 | 场景 | 验证码有效期 |
|----------|------|--------------|
| `POST /api/auth/send-register-code` | 注册邮箱验证 | 10 分钟 |
| `POST /api/auth/forgot-password` | 找回密码邮箱验证 | 15 分钟 |

### 降级行为

- 未配置时 `isEmailConfigured()` 返回 `false`
- 相关接口返回 `503 邮件服务暂未配置，请稍后重试`

## 短信服务配置

### 服务商支持

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| `aliyun` | 阿里云短信服务 | 生产环境 |
| `mock` | 控制台打印验证码 | 开发/测试环境 |

### 阿里云 SMS 配置步骤

1. **创建 RAM 子账号**
   - 登录 [RAM 控制台](https://ram.console.aliyun.com/)
   - 创建用户，勾选「OpenAPI 调用访问」
   - 授权策略：`AliyunDysmsFullAccess`（短信服务完全访问权限）
   - 保存 AccessKey ID 和 Secret

2. **开通短信服务**
   - 登录 [短信服务控制台](https://dysms.console.aliyun.com/)
   - 申请短信签名（需审核，1-2 个工作日）
   - 申请短信模板（需审核）

3. **创建短信模板**

   **模板 1：绑定/解绑/换绑验证码**
   ```
   您的验证码为${code}，10分钟内有效。如非本人操作请忽略。
   ```

   **模板 2：找回密码验证码**
   ```
   您找回密码的验证码为${code}，15分钟内有效。如非本人操作请忽略。
   ```

4. **配置环境变量**
   ```bash
   SMS_PROVIDER="aliyun"
   SMS_ACCESS_KEY_ID="LTAI5t..."
   SMS_ACCESS_KEY_SECRET="xxxxxxxx"
   SMS_SIGN_NAME="你的签名名称"
   SMS_TEMPLATE_CODE="SMS_XXXXXXX"           # 绑定/解绑模板
   SMS_TEMPLATE_CODE_RESET="SMS_XXXXXXX"     # 找回密码模板
   ```

### 业务场景

| 接口路径 | 场景 | 验证码有效期 | 模板 |
|----------|------|--------------|------|
| `POST /api/auth/forgot-password` | 找回密码（手机号渠道） | 15 分钟 | `SMS_TEMPLATE_CODE_RESET` |
| `POST /api/auth/send-phone-code` | 手机号绑定/解绑/换绑 | 10 分钟 | `SMS_TEMPLATE_CODE` |

### 降级行为

- `SMS_PROVIDER=mock` 时验证码打印到控制台，格式：`[SMS-MOCK] → 13800138000: 验证码 123456`
- 未配置阿里云 AK 时抛出 `SMS_NOT_CONFIGURED` 错误

## 安全配置要求

### 密钥管理

| 要求 | 说明 | 操作方式 |
|------|------|----------|
| `.env` 文件权限 | 仅应用运行用户可读 | `chmod 600 .env` |
| 版本控制 | `.env` 不入库 | 已在 `.gitignore` 中配置 |
| 生产密钥隔离 | 生产/测试环境使用不同密钥 | 创建独立 RAM 子账号 |
| 定期轮换 | 建议每 90 天轮换一次密钥 | 阿里云 RAM 控制台操作 |

### 阿里云 RAM 权限最小化

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "dysms:*",
      "Resource": "*"
    }
  ]
}
```

### 网络要求

| 服务 | 出站端口 | 目标地址 | 协议 |
|------|----------|----------|------|
| SMTP (SSL) | 465 | `smtpdm.aliyun.com` | TCP |
| SMTP (TLS) | 587 | `smtpdm.aliyun.com` | TCP |
| 阿里云 SMS | 443 | `dysmsapi.aliyuncs.com` | HTTPS |

**防火墙配置**：确保服务器安全组允许以上出站连接。

### 敏感信息保护

- 所有密钥通过环境变量注入，不硬编码在代码中
- 验证码在数据库中存储时使用 SHA-256 哈希
- 日志中手机号脱敏显示（如 `138****8000`）

## 限流策略

系统内置多层限流保护，防止恶意刷接口。所有限流状态持久化到 `server/logs/` 目录，服务重启后不丢失。

### 限流参数表

| 限流维度 | 时间窗口 | 上限 | 持久化文件 | 说明 |
|----------|----------|------|------------|------|
| IP 登录失败 | 15 分钟 | 10 次 | `.login-rate-limit.json` | 防暴力破解 |
| 账号登录失败 | 30 分钟 | 5 次 | `.account-rate-limit.json` | 防分布式攻击 |
| IP 发送验证码 | 1 小时 | 5 次 | `.forgot-rate-limit.json` | 防邮件/短信轰炸 |
| 手机号短信间隔 | 60 秒 | 1 次 | `.phone-rate-limit.json` | 防频繁发送 |
| 手机号短信总量 | 1 小时 | 5 次 | `.phone-rate-limit.json` | 防持续轰炸 |

### 限流触发响应

```json
{
  "error": "验证码发送过于频繁，请稍后重试",
  "retry_after_seconds": 45
}
```

### 目录权限要求

```bash
# 确保 server/logs/ 目录存在且有写权限
mkdir -p server/logs
chmod 755 server/logs
```

## 服务验证方法

### 1. 验证邮箱服务

**发送测试邮件**

```bash
# 调用注册验证码接口（替换为真实邮箱）
curl -X POST https://osneosmart.com/api/auth/send-register-code \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com"}'
```

**预期成功响应**

```json
{
  "success": true,
  "email_sent": true,
  "message": "验证码已发送到您的邮箱，请查收",
  "support_hint": null
}
```

**验证步骤**：
1. 检查目标邮箱收件箱
2. 如未收到，检查垃圾邮件文件夹
3. 查看服务器日志确认发送状态

### 2. 验证短信服务

**发送测试短信**

```bash
# 先获取登录 token
TOKEN=$(curl -s -X POST https://osneosmart.com/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"your_password"}' | jq -r '.token')

# 调用发送手机验证码接口
curl -X POST https://osneosmart.com/api/auth/send-phone-code \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"phone":"13800138000","scene":"bind"}'
```

**预期成功响应**

```json
{
  "success": true,
  "sms_sent": true
}
```

**验证步骤**：
1. 检查目标手机是否收到短信
2. 如未收到，查看服务器日志中的 `[SMS-ALIYUN]` 前缀日志
3. 登录阿里云短信控制台查看发送记录

### 3. 网络连通性测试

```bash
# 测试 SMTP 连通性
telnet smtpdm.aliyun.com 465

# 测试阿里云 SMS 连通性
curl -I https://dysmsapi.aliyuncs.com
```

### 4. 配置状态检查

```bash
# 检查服务健康状态（需要内部接口支持）
curl https://osneosmart.com/api/system/health
```

## 日志监控

### 关键日志标识

| 日志前缀 | 含义 | 级别 |
|----------|------|------|
| `[SMS-MOCK]` | Mock 模式短信发送 | INFO |
| `[SMS-ALIYUN] ✓` | 阿里云短信发送成功 | INFO |
| `[SMS-ALIYUN] ✗` | 阿里云短信发送失败 | ERROR |
| `SMS_SEND_FAILED` | 短信发送失败详情 | ERROR |
| `SMS_SEND_ERROR` | 短信 SDK 调用异常 | ERROR |
| `SMS_NOT_CONFIGURED` | 短信服务未配置 | ERROR |
| `[forgot-password] ✓` | 找回密码邮件发送成功 | INFO |
| `[forgot-password] ✗` | 找回密码邮件发送失败 | ERROR |
| `[register-code]` | 注册验证码邮件发送结果 | INFO/ERROR |
| `[send-phone-code] ✗` | 手机验证码短信发送失败 | ERROR |

### 日志采集建议

**阿里云 SLS 配置示例**

```yaml
# 采集规则
- logstore: supply-os-app
  patterns:
    - "\[SMS-.*\]"      # 短信相关日志
    - "\[forgot-password\]"  # 找回密码日志
    - "\[register-code\]"    # 注册验证码日志
    - "SMS_"           # SMS 错误码
```

**告警规则建议**

| 告警条件 | 阈值 | 通知方式 |
|----------|------|----------|
| `SMS_SEND_FAILED` 出现次数 | > 5次/小时 | 钉钉/邮件 |
| `SMTP` 连接超时 | > 3次/10分钟 | 钉钉/邮件 |
| 限流触发次数 | > 100次/小时 | 邮件（可能遭攻击） |

## 故障排查

### 邮箱服务故障

| 现象 | 可能原因 | 排查步骤 | 解决方案 |
|------|----------|----------|----------|
| 返回 503 `邮件服务暂未配置` | SMTP 环境变量未配置 | 检查 `.env` 文件 | 配置 `SMTP_HOST/USER/PASS` |
| 发送超时 | SMTP 端口被防火墙拦截 | `telnet smtpdm.aliyun.com 465` | 安全组放行 465 端口 |
| 认证失败 | 密码错误或账号被锁定 | 登录阿里云邮件推送控制台 | 重置 SMTP 密码 |
| 邮件进垃圾箱 | SPF/DKIM 记录未配置 | 检查域名 DNS 解析 | 配置 SPF、DKIM、DMARC |
| 发送频率限制 | 阿里云日发送量超限 | 查看阿里云控制台用量统计 | 提升发送额度或优化发送策略 |

### 短信服务故障

| 现象 | 可能原因 | 排查步骤 | 解决方案 |
|------|----------|----------|----------|
| 返回 `SMS_NOT_CONFIGURED` | `SMS_PROVIDER` 未设为 `aliyun` | 检查 `.env` | 设置 `SMS_PROVIDER=aliyun` |
| 返回 `SMS_SDK_INIT_FAILED` | SDK 依赖缺失 | `npm ls @alicloud/dysmsapi20170525` | `npm install` |
| 返回 `SMS_SEND_FAILED: isv.ACCOUNT_NOT_EXISTS` | AccessKey 无效 | 阿里云 RAM 控制台检查 | 重新创建 AK 或检查状态 |
| 返回 `SMS_SEND_FAILED: isv.SMS_SIGNATURE_ILLEGAL` | 签名未审核或不存在 | 阿里云短信控制台检查 | 等待签名审核通过 |
| 返回 `SMS_SEND_FAILED: isv.SMS_TEMPLATE_ILLEGAL` | 模板未审核或参数不匹配 | 检查模板内容和变量 | 确保模板变量为 `${code}` |
| 返回 `isv.BUSINESS_LIMIT_CONTROL` | 触发阿里云侧频率限制 | 阿里云控制台查看发送记录 | 等待限制解除或申请提升额度 |
| 短信延迟到达 | 运营商通道拥堵 | 查看阿里云发送状态报告 | 通常 1-5 分钟内到达，无需处理 |

### 数据库排查

```sql
-- 查看最近的验证码发送记录
SELECT user_key, phone, code_type, used, email_sent, sms_sent, 
       email_error, sms_error, created_at, expires_at
FROM crm_password_resets
ORDER BY created_at DESC
LIMIT 20;

-- 查看发送失败的记录
SELECT * FROM crm_password_resets
WHERE email_sent = 0 OR sms_sent = 0
ORDER BY created_at DESC
LIMIT 10;
```

## 快速配置模板

### 生产环境 `.env` 配置（当前线上值）

```bash
# ═══════════════════════════════════════════════════════════════
# 邮箱与短信服务配置 - 生产环境
# ═══════════════════════════════════════════════════════════════

# ── 邮箱服务（SMTP）─────────────────────────────────────────────
# 服务商：阿里云邮件推送
SMTP_HOST="smtpdm.aliyun.com"
SMTP_PORT="465"
SMTP_USER="osneosmart@suyufan.online"
SMTP_PASS="<从密码管理器获取>"
SMTP_FROM="国际采购供应链平台 <osneosmart@suyufan.online>"

# ── 短信服务（阿里云 SMS）───────────────────────────────────────
# 必须设置 SMS_PROVIDER=aliyun 才会启用真实短信发送
SMS_PROVIDER="aliyun"

# 阿里云 RAM 子账号 AccessKey（需有 dysms 权限）
# ⚠️ 敏感信息：从密码管理器或运维负责人处获取
SMS_ACCESS_KEY_ID="<从密码管理器获取>"
SMS_ACCESS_KEY_SECRET="<从密码管理器获取>"

# 短信签名（已在阿里云控制台审核通过）
SMS_SIGN_NAME="云境智展"

# 短信模板 CODE（已在阿里云控制台审核通过）
# 模板内容：您的验证码为${code}，10分钟内有效。如非本人操作请忽略。
SMS_TEMPLATE_CODE="SMS_511295419"

# 找回密码专用模板
# 模板内容：您找回密码的验证码为${code}，15分钟内有效。如非本人操作请忽略。
SMS_TEMPLATE_CODE_RESET="SMS_511345407"
```

> **⚠️ 安全提示**：SMTP 密码、阿里云 AccessKey 等敏感信息不存储在代码仓库中，请从密码管理器或运维负责人处获取。
