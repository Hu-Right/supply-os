- `src/main.tsx` 是唯一入口，使用 `react-dom/client` 的 `createRoot` 挂载到 `#root`，在 `<StrictMode>` 下按自顶向下顺序包裹 `ErrorBoundary` → `LocaleProvider` → `App`，形成「渲染异常兜底 → 多语言上下文 → 业务根组件」的全局能力链。
- `ErrorBoundary` 为类组件，通过 `getDerivedStateFromError` + `componentDidCatch` 捕获子树错误并渲染带“返回首页”按钮的降级页面，避免整站白屏；错误文案通过 `i18n.getFixedT` 获取以支持多语言。
- `src/App.tsx` 是约 2500 行的单文件巨型根组件，集中持有认证/会员/表单/筛选/AI 匹配/CRM 日志等所有模块级状态，并通过 `activeTab`（1~7）+ `isTrainingRoute` 在多个业务视图间切换；独立页面跳转则通过监听 `window.location.hash`（如 `#training`、`#procurement`）实现，无需引入 React Router。
- 数据层采用浏览器原生 `fetch` 直连后端 REST API（`/api/leads`、`/api/suppliers/custom`、`/api/auth/user?user_key=...`），用户会话经 `localStorage` 键 `supply_os_auth_user` 持久化；静态演示数据从同级 `@/data/index.ts` 导入，类型定义来自 `@/types`。
- 样式体系基于 Tailwind CSS v4，由 `src/index.css` 统一注入并通过 `@theme` 扩展 primary / secondary / accent 色板，组件内直接使用原子类完成布局与配色。
