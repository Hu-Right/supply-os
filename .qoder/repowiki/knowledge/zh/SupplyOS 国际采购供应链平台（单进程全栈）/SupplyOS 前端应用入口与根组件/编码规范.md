- 全局状态集中在 App 根组件内用 useState/useEffect 维护，子模块仅通过 props 或 Context 消费，不自行拉取远端数据。
- 表单提交统一先遍历 DOM 元素调用 `setCustomValidity` + `reportValidity()` 触发浏览器原生校验，再发起 `fetch` POST 请求。
- 用户会话通过 `localStorage` 键 `supply_os_auth_user` 持久化，登录后立即调用 `/api/auth/user?user_key=...` 刷新服务端状态。
- 所有文案通过 `useLocale()` 提供的 `t(key, params)` 函数获取，禁止在 JSX 中硬编码中英文字符串。
- 导航与路由通过 `window.location.hash` 监听 `hashchange` 事件实现，无需引入 React Router。
