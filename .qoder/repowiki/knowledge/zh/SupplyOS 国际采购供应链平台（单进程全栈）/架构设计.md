- 单一 Node.js 进程同时承载前端与后端：`server.ts` 启动 Express 应用，在 `/api/*` 下实现用户注册登录、会员计划、支付订单、供应商入驻、线索管理、UNSPSC 桥接回填等 REST 接口；Vite dev server 通过 `createServer` 注入到同一进程，生产构建后由 esbuild 将 `server.ts` 打包为 `dist/server.cjs` 并由 `npm start` 运行。
- 共享类型契约：`src/types.ts` 中导出的 `Lead`、`Supplier` 等 TypeScript 类型被前端组件与 `server.ts` 共同引用，构成前后端唯一的数据契约，避免手写 DTO。
- 数据库自举：`ensureProcurementSchema` 在首次连接时自动 `CREATE TABLE IF NOT EXISTS` 并增量 `ALTER TABLE` 补齐列/索引，配合 `backfillUserIds`、`syncUnspscBridgeFull` 等回填脚本，使仓库可零迁移脚本直接拉起。
- 运行时配置：`PAYMENT_MODE=live|mock`、支付宝/微信各密钥环境变量由 `getPaymentRuntimeConfig` 统一解析，并可从 `crm_payment_provider_configs` 表热加载覆盖，所有子模块通过该函数读取支付开关。
- 开发体验：`vite.config.ts` 通过 `@` 别名指向 `src/`，`tsconfig.json` 启用 `bundler` 解析与 `noEmit`，`package.json` 的 `dev` 使用 tsx 直跑 `server.ts`，`build` 先 Vite 再 esbuild 双阶段产出。
