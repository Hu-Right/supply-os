- `src/main.tsx` 作为唯一入口，使用 `react-dom/client` 的 `createRoot` 挂载到 `#root`，并在 `<StrictMode>` 下依次包裹 `ErrorBoundary` → `LocaleProvider` → `App`，形成自顶向下的全局能力链：渲染异常兜底 → 多语言上下文 → 业务根组件。
- `ErrorBoundary` 是类组件，通过 `getDerivedStateFromError` + `componentDidCatch` 捕获子树错误，失败时渲染带“返回首页”按钮的降级页面，避免整站白屏。
- `src/App.tsx` 是单文件巨型根组件（~2500 行），集中管理所有模块级状态（认证、会员、表单、筛选、AI 匹配、CRM 日志等）并通过 `activeTab` + `isTrainingRoute` 在多个业务视图间切换，同时以 hash 路由 (`#training`, `#procurement`) 驱动独立页面跳转。
- 数据层采用浏览器原生 `fetch` 直连后端 REST API（`/api/*`），配合 `localStorage` 持久化 `supply_os_auth_user`；静态演示数据通过 `@/data` 别名从同级 `data/index.ts` 导入，类型定义来自 `@/types`。
- 样式体系基于 Tailwind CSS v4（`@import "tailwindcss"` + `@theme` 自定义色板），由 `src/index.css` 统一注入，组件内直接使用原子类完成布局与配色。
